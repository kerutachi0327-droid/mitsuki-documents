# CLAUDE.md

## プロジェクト
OTOMIZU 関係者（個人事業主）のスケジュール共有アプリ。1人が複数案件・複数役割に配置される（多角的配置）前提。

## 技術方針
- ホスティング：Netlify
- DB / 認証：Supabase。権限は RLS で制御する（自分の予定のみ編集、ログイン済みメンバーは全員閲覧）
- タイムゾーン：Asia/Tokyo
- スマホでの閲覧・入力を最優先

## ルール
- API キー・トークンはコードやチャットに書かない。クラウド環境のネットワークシークレット、または Netlify の環境変数に置く
- Supabase の `anon` キー以外をフロントエンドに含めない
- スキーマ変更は `supabase/migrations/` に新しいファイルとして追加する
